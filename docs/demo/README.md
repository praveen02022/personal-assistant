# PersonalOS customer demo

**URL (local):** http://localhost:3000/demo. Sign in first at http://localhost:3000/login; a first sign-in on a device opens the guided welcome at `/welcome`.

The demo is a separate, clearly marked workspace for a fictional real-estate office, *Sunrise Realty (sample)*, in Chennai. The connected assistant (`/`, `/assistant`, `/connections`, `/settings`) is unchanged and stays available. **Exit demo** returns to it.

## Simulated vs live

| Area | In the demo | Live (real) |
|---|---|---|
| Briefing, schedule, leads, payments | Sample data (`apps/api/src/demo/demo-data.ts`) | — |
| Assistant answers | Scripted from sample data; no model, no OpenClaw (`demo-script.ts`) | Connected assistant: OpenClaw + model |
| Progress steps and sources | Simulated steps ("Reading sample calendar"); sources are sample records | Real tool events; sources = tools used + cited links |
| Approvals: lunch order, follow-ups | Simulated: ends with "No real order placed." / "No real message sent." | No real approval system yet (not offered) |
| Connections page | Services listed as *Simulated · not connected* | Microsoft 365 Calendar (read-only, real OAuth); voice; runtime status |
| Microphone, transcript review, Send | **Live** (real Azure speech-to-text; nothing is auto-sent) | Live |
| Read aloud, auto-speak, Stop | **Live** (real Azure text-to-speech of the sample answer) | Live |
| Theme Light / Dark / System | Live (remembered on this device) | Live |

**How the backend enforces the demo's limits:**
- `DemoModule` has no access to the gateway, integrations, MCP tools, voice providers, Prisma or `fetch`. `test/demo.isolation.spec.ts` checks its imports.
- Demo action endpoints accept only fixed sample IDs. Recipients, amounts and outcomes come from the server, never the client.
- `test/demo.e2e.spec.ts` runs a full demo session and asserts:
  - zero outbound HTTP
  - zero OpenClaw sends or sessions
  - zero conversations, tasks or integration rows
  - every demo audit entry is marked `simulated: true`
- Every demo response carries the header `X-PersonalOS-Demo: simulated`.
- Demo state lives in memory per user; **Reset demo** (sidebar) restores it.

## Three-minute presentation script

**0:00 Welcome (20 s).** Sign in. *"PersonalOS is a voice-first assistant for running your business day. You can explore it with sample data, or set it up with your own accounts."* Point at the two choices and pick **Try the demo**.

**0:20 Briefing (40 s).** *"This is a sample real-estate office. The violet bar means everything here is sample data, and actions are simulated."*
- Walk through the four highlights: payment due, new leads, approvals waiting, site visits.
- Then today's schedule.
- Point at **Sources** under the schedule: *"Every important fact shows where it came from."*

**1:00 Assistant (50 s).** Open **Assistant**, hold the mic and say *"What follow-ups are pending?"* (or tap the suggestion).
- *"Your words appear as text first; nothing is sent until you press Send."* Press Send.
- Point at the live steps ("Checking sample CRM", "Drafting follow-up messages") and the streamed answer.
- Show the three approval cards: two drafts and one **Failed** reminder with its reason.
- Press **Read aloud** and then **Stop**.

**1:50 Lunch approval (50 s).** Ask *"Order lunch for the team."* The answer proposes an order and an approval card shows the vendor, delivery and the **total of ₹1,762**.
- Click **Review & approve**. The dialog repeats the items and the total, and notes that no money moves.
- Confirm. The card turns **Completed** with **"No real order placed."**, and the timeline reads Proposed → Approved → Completed.
- *"Nothing happens without your approval, and you can always see what was proposed, approved, done or failed."*

**2:40 Trust and next step (20 s).** Open **Connections**: *"Each service shows the access it would need and what it will never do."*
- Click **Exit demo** to show the connected Home: real status, and the real Microsoft 365 calendar connection, which is read-only.
- Toggle Dark mode from the account menu.
- Close with: *"We start read-only, and actions only ever run with your approval."*

**Before presenting:**
- Press **Reset demo**.
- Check the sidebar says **Assistant online**.
- Have a quiet room for the mic.
- The free speech-service tier allows about 10 requests a minute, so avoid rapid retries.
